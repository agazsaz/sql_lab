# sql_lab

**Внимание!** Все файлы, скрипты и дампы для сдачи этой лабораторной работы находятся в папке **[`db_lab`](./db_lab)** (нажмите на неё выше в списке файлов).

## Что находится в папке `db_lab`:
* `README.md` — полный отчет по лабораторной работе с выводами.
* `my.cnf` — конфигурационный файл MySQL (настройки логирования).
* `my_actions.log` — лог выполненных SQL-запросов (доказательство работы).
* `index_dump.sql` — дамп базы данных со всей структурой и тестовыми данными.
